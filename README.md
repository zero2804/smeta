# Сметы кровли

Приложение для смет на гидроизоляцию (ПВХ, битум, утепление) для телефона. Работает без интернета, все данные хранятся в самом телефоне.

## Файлы

| Файл | Что внутри |
|---|---|
| `data.js` | **Справочник материалов и работ** (цены по умолчанию) и **шаблоны смет** с формулами количества |
| `i18n.js` | Тексты на русском и узбекском, сумма прописью |
| `app.js` | Логика: экраны, расчёт, PDF, акт |
| `styles.css` | Оформление экранов и документа |
| `sw.js` | Работа без интернета. **При каждом обновлении файлов увеличьте `CACHE = 'smeta-vN'`** |
| `tools/serve.js` | Локальный сервер для проверки: `node smeta/tools/serve.js` → http://localhost:5173 |
| `tools/make-icons.js` | Рисует иконки в `icons/` |

## Формулы в шаблонах

`S` — площадь (м²), `L` — длина парапета (м), `N` — воронки (шт), `T` — толщина утеплителя (в формуле в метрах, в программе вводится в мм).
`up(x, 10)` — округлить вверх до 10, `r2(x)` — до сотых, `ceil(x)` — вверх до целого.

Пример: `['pvc_geo', 'up(S*1.12,5)']` — ПВХ = площадь + 12%, округлить вверх до 5 м².

## Как поставить на телефон

Приложение нужно выложить на любой хостинг с HTTPS (GitHub Pages, Netlify, Cloudflare Pages) — это просто папка с файлами, сервер не нужен.
Затем открыть ссылку в Chrome на телефоне → меню ⋮ → «Добавить на главный экран».

Резервная копия: Настройки → «Сохранить копию (файл)». Её можно загрузить на другом телефоне.
